# 幣盤

直接玩：<https://cdn.jsdelivr.net/gh/Varun1012/coinpit@gh-pages/index.html>

四人加密棋盤。價格 = 基本面 P* + 市場 PΔ，每名玩家結束回合收一根線。

- 開局現金 **150 USDT**。恐貪指數從 **50（中性）** 開始，流動性在正中。
- 棋子**順時針**走。起點在右下角，空投在左下角。每經過起點免費 **20 USDT**。
- 冷庫、機房、天台、港口要等**別的玩家踩到**才收租。一級擲一顆骰，**1–6 USDT**；每升一級多一顆骰。
- 升到二級要 **150 USDT**，之後每級再加 150。
- 右上角「盜錢包」拿走一名對手現金的 50%。骰子顯示點數。擲出 6 可再擲，三連六直接送到盜錢包。
- 淨值先到 **100,000 USDT**，或其餘三人破產，即勝。
- 可跟 AI 開局，或在已部署的版本開房對決。這個網頁版可以跟 AI 玩，並附原創循環配樂「夜盤」（D dorian、88 BPM、32 小節）。
