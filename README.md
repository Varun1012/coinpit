# 幣盤

四人加密棋盤。價格 = 基本面 P* + 市場 PΔ，每名玩家結束回合收一根線。

- 開局現金 **150 USDT**。恐貪指數從 **50（中性）** 開始，流動性在正中。
- 棋子**順時針**走。起點在右下角，空投在左下角。每經過起點免費 **20 USDT**。
- 右上角「盜錢包」拿走一名對手現金的 50%。
- 骰子顯示點數。擲出 6 可再擲，三連六直接送到盜錢包。
- NFT 房不靠踩格收租，分成來自交易費和每根 K 線的外部流動。
- 淨值先到 **100,000 USDT**，或其餘三人破產，即勝。
- 可跟 AI 開局，或開房對決。房間裡空著的位子由 AI 替補。有人中途離開，該席也改由 AI 接手。

## 本機

```bash
npm install
npm run dev
```

線上對決的握手要經過 `/api/rtc`。這個專案在本機可以跟 AI 玩；跟朋友開房請用已部署的幣盤（同一個房間號碼）。
