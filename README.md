# 幣盤

直接玩：<https://varun1012.github.io/coinpit/>

四人加密棋盤。價格 = 基本面 P* + 市場 PΔ，每名玩家結束回合收一根線。

- 開局現金 **150 USDT**。恐貪指數從 **50（中性）** 開始，流動性在正中。
- 棋盤 **40 格**，**順時針**走。每次擲三顆：兩顆點數骰相加走路，一顆空投骰只有 **Free** 會順便入帳。踩到空投格則直接領幣。每經過起點免費 **20 USDT**。
- 冷庫、機房、天台、港口、礦機等房子，要等**別的玩家踩到**才收租。一級擲一顆骰，**1–6 USDT**；每升一級多一顆骰。
- 升到二級要 **150 USDT**，之後每級再加 150。
- **交稅**抽走手上 USDT 的 10%。
- 右上角「盜錢包」：停在該格後再擲兩顆點數骰，**合計 12** 才能拿走一名對手 50% 的 USDT。
- 基本面卡和市場卡會發錢、罰款、向每人收錢、維修房子，也會把你送到起點、空投、交稅、盜錢包，或退後三格。
- 恐貪指數**越高越貪婪**。開局 50。
- 淨值先到 **10,000 USDT**，或其餘三人破產，即勝。
- 有擲骰、走路、升級、交稅等音效，以及循環配樂「夜盤」。
